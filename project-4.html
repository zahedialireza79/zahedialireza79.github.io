Cable-Driven Painting Robot

A lightweight cable-driven robotic system designed for artistic motion and portable wall-mounted operation.

Project Overview

Cable-driven robots use tensioned wires instead of rigid links, allowing lightweight and highly portable designs. They are well-suited for large workspaces, wall-mounted installations, and artistic motion.

This project involved designing and building a compact cable-driven painting robot named Kamal-ol-Molk, inspired by the renowned Iranian painter. The system can be mounted using only two nails on a wall, making it extremely easy to deploy in different environments.

I designed the robot’s mechanical structure in SolidWorks, created the custom PCB for motor control, and developed the embedded firmware required for synchronized cable motion. The system was engineered to produce smooth, controlled strokes suitable for creative and artistic tasks.

This project strengthened my experience in mechanical design, custom electronics, and embedded robotics for creative applications.
